# التعامل مع النصوص في HTML

## مقدمة ونظرة عامة

معظم محتوى الويب عبارة عن نصوص، لذلك ستتعامل كثيرًا مع **HTML text elements**. في هذا الدرس ستتعلم العناصر الأكثر استخدامًا لكتابة نص واضح ومنظم داخل الصفحة.

ستتعلم:

- إنشاء `paragraphs` و`headings`.
- استخدام `strong` للنص المهم دلاليًا و`em` للنص الذي يحتاج إلى emphasis (تأكيد).
- فهم علاقات `parent` و`child` و`sibling` بين العناصر.
- كتابة `HTML comments` لا تظهر للمستخدم.

## Paragraphs

قد تتوقع أن يعرض هذا الكود فقرتين، لكن browser لا يعتبر الانتقال لسطر جديد (`line breaks`) داخل `body` فقرة جديدة:

```html
<body>
  Lorem ipsum dolor sit amet, consectetur adipiscing elit. Ut enim ad minim
  veniam, quis nostrud exercitation ullamco laboris.
</body>
```

عندما يقرأ browser هذا النص، يضغط line breaks و المسافات الفارغة الإضافية (`extra whitespace`) إلى space واحد، فيظهر المحتوى كسطر طويل. لإنشاء فقرة فعلية، استخدم عنصر `<p>`:

```html
<body>
  <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit.</p>
  <p>Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris.</p>
</body>
```

كل `<p>` هو عنصر مستقل وله معنى واضح. لا تعتمد على empty lines أو تكرار المسافات لتحديد بنية المحتوى؛ استخدم HTML element المناسب.

## Headings

تظهر `headings` عادةً بحجم أكبر ووزن أثقل لأنها توضّح hierarchy المحتوى (ترتيب المحتوى في الصفحة كسلسلة) يوجد **ستة مستويات** تبدأ من `<h1>` وتنتهي عند `<h6>`:

```html
<h1>عنوان الصفحة</h1>
<h2>قسم رئيسي</h2>
<h3>قسم فرعي</h3>
<h6>أدق مستوى من العناوين</h6>
```

استخدم `<h1>` لعنوان الصفحة أو المقال الرئيسي، ثم استخدم المستويات الأقل للأقسام التابعة له. `h2` ليس مجرد طريقة لجعل النص أصغر من `h1`؛ إنه يعبّر عن مستوى في document hierarchy. أما الحجم والألوان فمكانها CSS.

## Strong element (عنصر الأهمية)

يمنح عنصر `<strong>` النص مظهرًا bold (عريض)، والأهم أنه يضيف معنى **importance (الأهمية)**. قد تستخدم screen readers (قارئات الشاشة) نبرة مختلفة عند قراءة هذا المحتوى.

```html
<strong>تنبيه مهم</strong>

<p>يجب حفظ الملف <strong>قبل</strong> فتحه في browser.</p>
```

استخدم `<strong>` عندما تكون أهمية النص جزءًا من المعنى، لا لمجرد تغيير مظهره. ستتعلم لاحقًا طرق جعل النص bold بصريًا فقط باستخدام CSS.

## Em element (عنصر التأكيد)

يضيف `<em>` مظهرًا italic (مائلًا) ومعنى **emphasis (التأكيد)** للنص. وكما هو الحال مع `<strong>`، فهذا المعنى قد يكون مهمًا لبرامج accessibility (إتاحة الوصول).

```html
<em>هذا النص يحتاج إلى emphasis.</em>

<p>هذا هو <em>الجزء الأهم في الجملة</em>.</p>
```

يمكنك nesting (تداخل العناصر) بين عناصر النص عندما يخدم ذلك المعنى:

```html
<strong><em>تحذير مهم جدًا</em></strong>
```

## Nesting (تداخل العناصر) و indentation (المسافة البادئة)

عندما تضع عنصرًا داخل عنصر آخر، تنشئ علاقة `parent` (العنصر الأب) و`child` (العنصر الابن). العنصر الخارجي هو `parent`، والعنصر الموجود داخله هو `child`:

```html
<body>
  <p>هذه الفقرة child لعنصر body.</p>
</body>
```

يمكن للـ `parent` أن يحتوي على أكثر من `child`. والعناصر الموجودة في نفس المستوى ولها نفس `parent` تسمى `siblings` (العناصر الأشقاء):

```html
<body>
  <p>First paragraph</p>
  <p>Second paragraph</p>
</body>
```

في المثال السابق، الفقرتان siblings، وعنصر `body` هو parent لهما. استخدم indentation بمقدار مسافتين لكل nesting level حتى تكون هذه العلاقات واضحة لك ولأي developer يقرأ الكود.

## HTML comments (التعليقات)

لا تظهر `HTML comments` (تعليقات HTML) في الصفحة، لكنها تترك context (سياقًا توضيحيًا) مفيدًا للمطورين. اكتبها بين `<!--` و`-->`:

```html
<!-- هذا التعليق يشرح سبب وجود القسم التالي -->
<p>هذا النص فقط هو الذي يظهر للمستخدم.</p>
```

لا تضع معلومات سرية داخل comments؛ فهي مخفية بصريًا فقط ويمكن لأي شخص رؤية source code.
