# تهيئة البيئة

![شعار Visual Studio Code](https://static.cdnlogo.com/logos/v/35/vs-code_thumb.png)

في الدروس القادمة سنستخدم `Visual Studio Code` لكتابة ملفات مثل `HTML` و`CSS` و`JavaScript` وتشغيلها. لذلك قبل أن نبدأ في البرمجة، من المهم أن تثبّت المحرر المناسب وتعرف سبب استخدامه.

## ماذا ستتعلم؟

في هذا الدرس ستتعرف على:

- ما الفرق بين محرر النصوص ومحرر الأكواد.
- لماذا لا نستخدم `Word` لكتابة الكود.
- لماذا نستخدم `VS Code` في هذه المنصة.
- كيفية تثبيت المحرر على نظام التشغيل الخاص بك.
- كيفية فتح أول مجلد وملف برمجي داخل المحرر.

## ما هو Visual Studio Code؟

محرر النصوص هو برنامج تكتب فيه الملفات وتقرأها وتعدّلها. أما محرر الأكواد فهو محرر نصوص متخصص في البرمجة، ويقدّم أدوات تساعدك على:

- تلوين الكلمات البرمجية حسب معناها.
- إغلاق الأقواس وعلامات الاقتباس تلقائيًا.
- اكتشاف بعض الأخطاء أثناء الكتابة.
- تنسيق الكود بشكل أفضل.
- إضافة أدوات وم extensions لتسهيل العمل.
- إدارة المشروع بسهولة مع `Git`.

`VS Code` مجاني، خفيف، وسهل الاستخدام، ويعمل بشكل مشابه على أنظمة التشغيل المختلفة. لذلك نستخدمه في هذه المنصة لتوحيد طريقة التعلم وتسهيل المساعدة والدعم.

## لماذا لا نستخدم Word؟

برامج مثل `Microsoft Word` أو `LibreOffice Writer` مناسبة لكتابة المستندات، لكنها ليست مناسبة لكتابة الكود.

سبب ذلك بسيط: ملفات الكود تحتاج إلى أن تبقى نصًا نقيًا، دون تنسيقات أو بيانات إضافية مرتبطة بالصفحة. أما `Word` فيضيف معلومات عن الخطوط والألوان وعناصر التنسيق، ما يجعل الملف غير مناسب للمتصفح أو أدوات البرمجة.

لهذا السبب نستخدم محررًا يحفظ النص كما هو، بحيث يمكن للمتصفح أو المترجم أو المحرر قراءته بشكل صحيح.

## لماذا نستخدم محرر أكواد؟

يمكنك كتابة الكود في محرر نصوص بسيط، لكن محرر الأكواد يوفر لك وقتًا وجهدًا، ويقلّل الأخطاء الشائعة. من أهم مزاياه:

- تلوين أجزاء الكود بشكل واضح.
- اقتراح أسماء الأوامر والخصائص أثناء الكتابة.
- إظهار الأخطاء قبل تشغيل المشروع.
- تنظيم المشروع داخل مجلدات.
- إمكانية إضافة إكسنتشنات حسب الحاجة.
- دعم التحكم بالإصدارات عبر `Git`.

<LessonNote>
  حمّل VS Code من [الموقع الرسمي](https://code.visualstudio.com/download) فقط.
</LessonNote>

## التثبيت على Windows

### 1. تنزيل برنامج التثبيت

افتح [صفحة تنزيل VS Code](https://code.visualstudio.com/download)، ثم اختر **Windows**. للمستخدم العادي، اختر **User Installer**؛ فهو لا يحتاج إلى صلاحيات المسؤول ويُثبت البرنامج لحسابك فقط.

### 2. تشغيل المثبت

افتح الملف الذي ينتهي بـ `.exe` من مجلد التنزيلات، ثم وافق على اتفاقية الاستخدام. اترك المسار المقترح كما هو واضغط **Next** حتى تصل إلى خيارات التثبيت.

فعّل خيار **Add to PATH** إن ظهر لك، ثم أكمل التثبيت بالضغط على **Install**. إضافة البرنامج إلى `PATH` تسمح بفتح المجلدات من الطرفية باستخدام الأمر `code`.

### 3. فتح المشروع من الطرفية / الـ Command Prompt

بعد انتهاء التثبيت، افتح أي من هذه الأدوات: **Terminal** أو **Command Prompt** أو **PowerShell**، ثم نفّذ الأمر التالي:

```powershell
cd path\to\your-project
code .
```

إذا ظهر لك مجلد المشروع داخل `VS Code`، فهذا يعني أن التثبيت تم بنجاح. إذا لم يتعرف النظام على الأمر `code`، أعد فتح الطرفية/الأمر، أو أعد تثبيت البرنامج مع تفعيل **Add to PATH**.

> يمكنك استخدام **Command Prompt (cmd)** أو **PowerShell** أو **Terminal** في Windows، وكلها تؤدي نفس الوظيفة الأساسية.

## التثبيت على macOS

### 1. تنزيل النسخة المناسبة

من [صفحة التنزيل](https://code.visualstudio.com/download) اختر **macOS**. اختر **Universal** إذا لم تكن تعرف نوع المعالج، أو اختر **Apple silicon** لأجهزة Apple الحديثة و**Intel** لأجهزة Mac الأقدم.

### 2. نقل التطبيق إلى Applications

افتح ملف `.dmg` الذي تم تنزيله، ثم اسحب `Visual Studio Code.app` إلى مجلد **Applications**. افتح المجلد وشغّل التطبيق بالنقر المزدوج.

![اختيار أمر code من Command Palette على macOS](https://code.visualstudio.com/assets/docs/setup/mac/shell-command.png)

### 3. تفعيل الأمر `code`

من داخل VS Code افتح **Command Palette** بالاختصار `Cmd + Shift + P`، وابحث عن الأمر التالي ثم شغّله:

```text
Shell Command: Install 'code' command in PATH
```

بعد ذلك، أغلق **Terminal** أو **iTerm** أو أي نافذة طرفية مفتوحة، وافتحها من جديد، ثم جرّب:

```bash
cd path/to/your-project
code .
```

> في macOS، تُعرف هذه النافذة غالبًا باسم **Terminal**، وفي بعض الأحيان **iTerm2**، وكلها تسمح لك بتشغيل الأوامر نفسها.

## التثبيت على Linux

تختلف الخطوات قليلاً حسب التوزيعة. استخدم مدير الحزم الخاص بتوزيعتك من [تعليمات Linux الرسمية](https://code.visualstudio.com/docs/setup/linux).

### Ubuntu و Debian

نزّل حزمة `.deb` من [صفحة التنزيل](https://code.visualstudio.com/download)، ثم افتحها بمتجر التطبيقات، أو نفّذ الأمر التالي من مجلد التنزيلات:

```bash
sudo apt install ./code_*.deb
```

### Fedora و RHEL و CentOS

نزّل حزمة `.rpm`، ثم ثبّتها باستخدام مدير الحزم:

```bash
sudo dnf install ./code-*.rpm
```

### Snap

إذا كانت توزيعتك تدعم `Snap`، يمكنك التثبيت بالأمر التالي:

```bash
sudo snap install code --classic
```

بعد التثبيت افتح مجلد المشروع من **Terminal** أو **Shell** الخاص بنظامك:

```bash
cd path/to/your-project
code .
```

> في Linux، غالبًا ما تُسمّى هذه النافذة **Terminal** أو **Shell**، وقد تستخدم أيضًا **GNOME Terminal** أو **Konsole** حسب توزيعتك.

<LessonNote>
  لا تستخدم أوامر Ubuntu على Fedora أو العكس. تحقق أولاً من اسم توزيعتك، ثم اتبع
  طريقة التثبيت المناسبة لها.
</LessonNote>

## بعد التثبيت

افتح `VS Code`، ثم أنشئ مجلدًا باسم `learning-project`. افتح هذا المجلد من **File > Open Folder**، ثم أنشئ داخله ملفًا باسم `hello.html` واكتب:

> إذا كنت تستخدم Windows، يمكنك فتح **Command Prompt (cmd)** أو **PowerShell** لتشغيل الأوامر، وليس فقط ما يسمى "طرفية". هذه الأنواع مختلفة في الاسم فقط، لكن جميعها تؤدي نفس المهمة.

```html
<h1>Hello, VS Code!</h1>
```

يمكنك بعد ذلك مشاهدة [هذا الفيديو الرسمي](https://share.google/11UVq86kn6fpGPJdN) لمعرفة أقسام VS code والبدء في استخدامه.

إذا كنت تستخدم جهازًا افتراضيًا (Virtual Machine)، ثبّت `VS Code` داخل الجهاز نفسه، لأنك ستعمل داخل البيئة التي ستشغل فيها مشاريعك. وإذا كنت تستخدم Windows مع `WSL`، فراجع [دليل التطوير باستخدام WSL](https://code.visualstudio.com/docs/remote/wsl) وثبّت إضافة `WSL` الرسمية.
إذا ظهر الملف في مستكشف الملفات وتمكنت من فتحه وتعديله، فالمحرر جاهز للعمل.

## المتصفح المدعوم من المنصة

في هذه المنصة، يقتصر دعمنا على متصفح غوغل كروم (Google Chrome) لكونه الخيار الأوسع استخداماً بين المطورين والمستخدمين.

- **أدوات مطور قوية:** يتضمن المتصفح أفضل أدوات المطور (Developer tools) التي ستعتمد عليها طوال المنهج الدراسي لفحص تطبيقات الويب الخاصة بك، واكتشاف الأخطاء (Debugging)، واختبارها.
- **التوافق التام مع المنهج:** رغم توفر أدوات مشابهة في متصفحات أخرى، إلا أن جميع الدروس، والتعليمات، وصور الشاشة مصممة بافتراض استخدامك لمتصفح كروم.

#### خلاصة القول

طريقة التثبيت تختلف حسب نظام التشغيل، لكنها جميعها تؤدي إلى نفس النتيجة: تنزيل النسخة الرسمية، إكمال التثبيت، ثم فتح مشروعك داخل `VS Code`. بمجرد أن تبدأ العمل داخل المحرر، يصبح المكان الأساسي لتجربة المهارات وبناء مشاريع الويب.
