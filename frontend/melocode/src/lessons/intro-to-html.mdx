# مقدمة إلى HTML وCSS

في هذا الدرس سنبدأ ببناء صفحات الويب فعليًا. ستتعرف على أساسيات `HTML` و`CSS`، وهما من أهم اللبنات التي تُبنى منها معظم صفحات الويب.

يجب أن تكون قد حمّلت VS code كي تتمكن من الممارسة مع هذا الدرس.

## HTML وCSS

تعمل `HTML` و`CSS` معًا لإنشاء ما تراه عند زيارة صفحة ويب.

- **HTML (HyperText Markup Language):** تحدد محتوى الصفحة وبنيتها. النصوص والروابط والقوائم والأزرار والعناوين كلها تُكتب باستخدام HTML.
- **CSS (Cascading Style Sheets):** تضيف التنسيق إلى عناصر HTML. فهي تتحكم في الألوان والخطوط والمسافات ومواقع العناصر وشكل الصفحة.

يمكنك تخيل صفحة الويب كمنزل: `HTML` يبني الجدران والغرف ويحدد ما يوجد داخلها، بينما `CSS` يضيف الألوان والديكور ويرتب هذه المكونات.

<LessonNote>
  يُشار أحيانًا إلى HTML وCSS على أنهما لغتا برمجة، لكنهما تقنيًا لغتا markup
  وstyle. لا تحتويان على منطق برمجي كالذي توفره JavaScript، بل تُستخدمان أساسًا
  لعرض المعلومات وتنسيقها.
</LessonNote>

أما `JavaScript` فهي لغة برمجة تضيف السلوك والتفاعل إلى الصفحة، مثل الاستجابة للنقر والتحقق من النماذج وتحديث المحتوى. ستتعلمها لاحقًا، لكن فهم HTML وCSS أولًا ضروري.

## العناصر والوسوم

تحدد HTML بنية الصفحة باستخدام **العناصر (Elements)**. معظم العناصر عبارة عن محتوى محاط بوسم فتح ووسم إغلاق.

وسم الفتح يخبر المتصفح أن العنصر بدأ، ويتكون عادةً من اسم داخل قوسين زاويين، مثل `<p>`. أما وسم الإغلاق فيخبر المتصفح أن العنصر انتهى، ويحتوي على `/` قبل الاسم، مثل `<p/>`.

```html
<p>هذا نص داخل فقرة.</p>
```

يتكون المثال السابق من ثلاثة أجزاء:

- `<p>` هو **opening tag**.
- `هذا نص داخل فقرة.` هو المحتوى.
- `</p>` هو **closing tag**.

يمكنك التفكير في العنصر على أنه حاوية للمحتوى. تخبر الوسوم المتصفح بنوع هذه الحاوية وكيف يتعامل مع ما بداخلها.

تحتوي HTML على مجموعة كبيرة من الوسوم الجاهزة. من المهم اختيار الوسم المناسب لمعنى المحتوى، وهذا يسمى **Semantic HTML**. استخدام العناصر الدلالية الصحيحة يساعد محركات البحث، كما يحسن الوصول إلى الصفحة للمستخدمين الذين يعتمدون على أدوات مثل screen readers.

<LessonNote>
  لا تختَر الوسم بناءً على شكله فقط. اختره بناءً على معنى المحتوى؛ أما الشكل
  والألوان فمكانها CSS.
</LessonNote>

## Void elements

بعض عناصر HTML لا تحتوي على محتوى، ولذلك لا تحتاج إلى closing tag. تسمى هذه العناصر **Void elements**، مثل:

```html
<br />
<img />
```

يُطلق عليها أحيانًا اسم self-closing tags، وقد تراها مكتوبة هكذا:

```html
<br >
<img >
```

## إنشاء HTML boilerplate

كل مستند HTML يحتاج إلى بنية أساسية قبل إضافة محتواه. تسمى هذه البنية **HTML boilerplate**.

### إنشاء الملف

أنشئ مجلدًا باسم `html-boilerplate`، ثم أنشئ بداخله ملفًا باسم `index.html`. تخبر اللاحقة `.html` الكمبيوتر بأن الملف مستند HTML.

من المعتاد أن يكون ملف الصفحة الرئيسية اسمه `index.html`، لأن web servers تبحث عن هذا الاسم افتراضيًا عندما يزور المستخدم الصفحة الرئيسية للموقع.

### DOCTYPE

يبدأ كل مستند HTML بإعلان doctype:

```html
<!DOCTYPE html>
```

يخبر هذا الإعلان المتصفح باستخدام معيار HTML الحديث، وهو HTML5. ضعه في السطر الأول من الملف. (أي يخبر المتصفح بإصدار HTML المستخدم)

### عنصر html

بعد doctype أضف عنصر `<html>`. هذا هو **root element** للمستند، وكل العناصر الأخرى ستكون بداخله أو descendants له.

```html
<!DOCTYPE html>
<html lang="ar"></html>
```

الخاصية `lang` هي **attribute** تضيف معلومات إلى العنصر. تحدد `lang="ar"` لغة النص، وهذا يساعد أدوات الوصول مثل screen readers على استخدام النطق المناسب.

### عنصر head

يحتوي عنصر `<head>` على معلومات مهمة عن الصفحة، لكنه لا يحتوي على العناصر التي تظهر للمستخدم مباشرة. يجب أن يكون أول عنصر داخل `<html>`.

أضف إليه `meta charset` وعنصر `title`:

```html
<!DOCTYPE html>
<html lang="ar">
  <head>
    <meta charset="UTF-8" />
    <title>صفحتي الأولى</title>
  </head>
</html>
```

يحدد `<meta charset="UTF-8">` طريقة ترميز الأحرف. وجوده مهم حتى تظهر الأحرف العربية والرموز الخاصة بشكل صحيح.

أما `<title>` فيحدد الاسم الذي يظهر في browser tab. إذا لم تضفه، قد يستخدم المتصفح اسم الملف مثل `index.html`، وهو اسم أقل فائدة للمستخدم.

### عنصر body

يحتوي عنصر `<body>` على كل ما سيظهر للمستخدم: النصوص والصور والقوائم والروابط والأزرار وغيرها. يوضع بعد `<head>` داخل `<html>`.

```html
<!DOCTYPE html>
<html lang="ar">
  <head>
    <meta charset="UTF-8" />
    <title>صفحتي الأولى</title>
  </head>

  <body></body>
</html>
```

وهكذا تصبح البنية الأساسية مكتملة. لإضافة محتوى، ضع عنصرًا داخل `<body>`:

```html
<!DOCTYPE html>
<html lang="ar">
  <head>
    <meta charset="UTF-8" />
    <title>صفحتي الأولى</title>
  </head>

  <body>
    <h1>مرحبًا بالعالم!</h1>
  </body>
</html>
```

## فتح ملف HTML في المتصفح

بعد حفظ `index.html`، يمكنك فتحه في المتصفح بعدة طرق:

- اسحب الملف من محرر النصوص وأسقطه في شريط عنوان المتصفح.
- استخدم الاختصار `Ctrl + O` في Windows أو `Cmd + O` في macOS، ثم اختر الملف.
- افتح المجلد من نظام الملفات واضغط مرتين على `index.html`.
- من الطرفية، افتح المجلد الذي يحتوي على الملف ثم استخدم الأمر المناسب لنظامك:

```bash
# Ubuntu
google-chrome index.html

# macOS
open ./index.html

# WSL
explorer.exe index.html

# windows
start index.html
```

يمكنك استخدام Google Chrome كمتصفح أساسي أثناء التدريب حتى تكون طريقة الاختبار متسقة. إذا كانت الصفحة فارغة، فتأكد من أنك أضفت محتوى داخل `<body>`. بعد تعديل الملف وحفظه، حدّث الصفحة في المتصفح لرؤية التغيير.

### اختصار VS Code

يوفر VS Code اختصارًا لإنشاء HTML boilerplate تلقائيًا. افتح ملفًا بامتداد `.html`، احذف محتواه، اكتب `!` في السطر الأول، ثم اضغط Enter لاختيار الاقتراح الأول.

قد يضيف VS Code السطر التالي أيضًا:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

يساعد هذا السطر في جعل الصفحة تتعامل مع أحجام الشاشات المختلفة. سنعود إلى موضوع responsive design في درس متقدم، ويمكنك إبقاء السطر كما هو الآن.

## مصادر إضافية

1. شاهد فيديو [HTML, CSS, JavaScript Explained](https://www.youtube.com/watch?v=gT0Lh1eYk78) للحصول على صورة سريعة عن كيفية عمل التقنيات الثلاث معًا.
2. اتبع فيديو Kevin Powell [Building Your First Web Page](https://www.youtube.com/watch?v=V8UAEoOvqFg&t=93s) وأنشئ ملف HTML بنفسك.
3. شغّل ملفك عبر [HTML validator](https://validator.w3.org/#validate_by_input). يساعدك validator على اكتشاف أخطاء مثل نسيان closing tags أو كتابة markup بشكل غير صحيح.

#### خلاصة القول

في هذا الدرس تعلمت أن `HTML` هو الهيكل الأساسي للمحتوى داخل الصفحة، بينما `CSS` هو الذي يضيف الشكل والتنسيق والهواء واللون. كما تعرفت على مفهوم العنصر، وكيف يتكون من **وسم فتح** و**محتوى** و**وسم إغلاق**، بالإضافة إلى العناصر الفارغة مثل `<img />` و`<br />` التي لا تحتاج إلى محتوى داخلي.

ثم شُرحت لك البنية الأساسية لأي صفحة HTML، والتي تسمى **HTML boilerplate**، وتتكون من `<!DOCTYPE html>` و`<html>` و`<head>` و`<body>`. لاحقًا يمكنك إضافة العناوين والنصوص والروابط وغيرها داخل `body` وعرضها في المتصفح.

بالتالي، الخطوة الأولى في بناء أي صفحة ويب هي كتابة هيكلها باستخدام HTML، ثم تنسيقها لاحقًا باستخدام CSS، وبعدها يمكن إضافة التفاعل عبر JavaScript في الدروس القادمة.
