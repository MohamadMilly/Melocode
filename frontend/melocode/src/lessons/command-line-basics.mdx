# أساسيات سطر الأوامر

عندما تسمع كلمة <Mark>Command Line</Mark> أو <Mark>Terminal</Mark> أو <Mark>Shell</Mark>، قد تتخيل شاشة سوداء فيها نصوص تبدو كأنها من فيلم الحاسب الآلي. لكن في الواقع، هذه الواجهة النصية هي واحدة من أهم أدوات المطورين، وهي تسمح لك بالتفاعل مباشرة مع جهاز الكمبيوتر عبر الأوامر.

في هذا الدرس ستتعلم كيف تتنقل بين المجلدات، تُنشئ ملفات ومجلدات، وتستخدم الطرفية بطريقة عملية ومباشرة.

## ما هو سطر الأوامر؟

سطر الأوامر هو <Mark>واجهة نصية</Mark> تسمح لك بإرسال أوامر مباشرة إلى نظام التشغيل. بدلًا من النقر على الأيقونات أو فتح القوائم، تكتب الأمر ثم يشتغل الجهاز حسب ما طلبته.

في بعض الأنظمة تسمى هذه الواجهة بـ <Mark>Terminal</Mark>، وفي أنظمة أخرى بـ <Mark>Command Prompt</Mark> أو <Mark>PowerShell</Mark> أو <Mark>Shell</Mark>. كل هذه الأسماء تشير إلى نفس الفكرة الأساسية: كتابة الأوامر في نافذة نصية بدلًا من استخدام الواجهة الرسومية.

لذلك، عندما تقوم بكتابة:

```bash
pwd
```

فهذا الأمر يطلب من النظام أن يطبع لك المسار الحالي (المجلد الذي أنت فيه الآن).

<LessonNote>
  لا تقلق إذا بدت الأوامر غامضة في البداية؛ كلّ مطور يبدأ من الصفر، ومع الوقت
  تصبح هذه الأوامر طبيعية جدًا.
</LessonNote>

## لماذا نتعلم سطر الأوامر؟

سطر الأوامر مهم جدًا لأنك ستستخدمه طوال رحلتك في البرمجة. عادةً ما يستخدمه المطورون لمجموعة من المهام مثل:

- التنقل داخل الملفات والمجلدات.
- إنشاء مجلدات أو ملفات جديدة.
- تشغيل أدوات مثل Git وnpm وNode.js.
- فتح مشروع كامل في محرر البرمجة.
- تثبيت البرامج وتحديثها.
- تصحيح أخطاء التطبيقات.

بمعنى آخر، سطر الأوامر هو <Mark>قاعدة عمليات</Mark> المطور. منه تبدأ معظم المهام، ومنه تُدار معظم المشاريع.

## فتح الطرفية

### على Linux

ابحث عن تطبيق <Mark>Terminal</Mark> من قائمة البرامج، أو استخدم الاختصار:

```bash
Ctrl + Alt + T
```

### على macOS

ابحث عن تطبيق <Mark>Terminal</Mark> داخل مجلد Utilities، أو استخدم محرك البحث <Mark>Spotlight</Mark>:

```bash
Cmd + Space
```

ثم اكتب <Mark>Terminal</Mark> واضغط Enter.

### على Windows

يمكنك فتح <Mark>PowerShell</Mark> أو <Mark>Command Prompt</Mark> أو حتى <Mark>Terminal</Mark> إذا كنت تستخدم Windows 11. كل هذه النوافذ تسمح لك بكتابة نفس الأوامر الأساسية في أغلب الأحيان.

عند فتح الطرفية، سترى عادةً سطرًا من النص يختتم برمز مثل <Mark>$</Mark> أو <Mark>%</Mark>. هذا الرمز يسمى <Mark>prompt</Mark>، ويعني أن الطرفية مستعدة لتلقي الأمر التالي.

## أول تجربة في الطرفية

لنجرّب أمرًا بسيطًا جدًا:

```bash
whoami
```

هذا الأمر يُظهر اسم المستخدم الحالي في النظام.

والأمر التالي:

```bash
pwd
```

يُظهر لك المسار الحالي، أي المكان الذي أنت فيه الآن داخل جهاز الكمبيوتر.

تجربة أخرى مفيدة:

```bash
ls
```

الأمر `ls` يطبع <Mark>محتويات المجلد الحالي</Mark>، أي الملفات والمجلدات الموجودة بداخله.

## أوامر أساسية للتنقل

من أهم الأوامر في سطر الأوامر هي تلك التي تسمح لك بالانتقال بين المجلدات.

### `pwd` — Print Working Directory

```bash
pwd
```

يُظهر لك المسار الحالي للفهرس الذي تعمل فيه، بمعنى: "أين أنت الآن؟"

### `ls` — List

```bash
ls
```

يعرض لك كل ما يوجد داخل المجلد الحالي.

إذا أردت رؤية تفاصيل أكثر:

```bash
ls -la
```

حيث تشير `-l` إلى التفاصيل، و`-a` إلى إظهار الملفات المخفية أيضًا.

### `cd` — Change Directory

```bash
cd folder-name
```

هذا الأمر ينتقل بك إلى مجلد معين داخل المجلد الحالي.

إذا أردت العودة إلى المجلد الأصلي (home directory):

```bash
cd ~
```

أما إذا أردت العودة إلى المجلد الأب مباشرة:

```bash
cd ..
```

وهذا يعني: "اذهب إلى المستوى الأعلى".

<LessonNote>
  الأمر `..` يعني "المجلد الأب". وهو من أكثر الرموز شيوعًا في سطر الأوامر.
</LessonNote>

### أمثلة

```bash
cd Desktop
cd ../Documents
cd ~
```

## إنشاء الملفات والمجلدات

### إنشاء مجلد جديد

```bash
mkdir my-folder
```

هذا الأمر ينشئ مجلدًا جديدًا باسم `my-folder` داخل المجلد الحالي.

### إنشاء ملف جديد

```bash
touch hello.txt
```

الأمر `touch` ينشئ ملفًا فارغًا إذا لم يوجد، أو يحدّث وقت آخر تعديل إذا كان موجودًا بالفعل.

### إنشاء هيكل مشروع بسيط

```bash
mkdir project
cd project
mkdir images
touch index.html
touch style.css
```

بهذا تكون قد أنشأت مشروعًا صغيرًا يتكون من مجلد `images` وملفين أساسيين: `index.html` و`style.css`.

## حذف وإعادة تسمية الملفات

### حذف ملف

```bash
rm file-name.txt
```

هذا الأمر يحذف الملف المحدد.

### حذف مجلد

```bash
rm -r folder-name
```

استخدم `-r` مع المجلدات، لأن `rm` وحده لا يزيل المجلدات عادةً.

<LessonNote>
  تحذير مهم: `rm` يحذف الملفات بشكل دائم. لذلك يجب استخدامه بحذر، خاصةً مع
  المجلدات.
</LessonNote>

### إعادة تسمية ملف أو مجلد

```bash
mv old-name.txt new-name.txt
```

الأمر `mv` يُستخدم أيضًا لنقل الملفات من مكان إلى آخر. لذلك يمكن أن تكون وظيفته مزدوجة: النقل أو إعادة التسمية.

### نسخ ملف

```bash
cp old-name.txt copy-of-old-name.txt
```

يُنشئ نسخة من الملف دون حذف النسخة الأصلية.

## استخدام سطر الأوامر مثل المحترفين

المبرمجون عادةً ما يكونون <Mark>كسولين</Mark> بطريقة إيجابية: لأنهم يكرّرون نفس المهام كثيرًا، لذلك يبتكرون اختصارات لتوفير الوقت.

### 1. النسخ واللصق

داخل الطرفية، النسخ واللصق لا يعملان كما في المتصفح دائمًا. في الغالب تُستخدم هذه الاختصارات:

- Windows / Linux: `Ctrl + Shift + C` و`Ctrl + Shift + V`
- macOS: `Cmd + C` و`Cmd + V`

لذلك، إذا كنت تنسخ أمرًا من المتصفح إلى الطرفية، فلا تستخدم اختصار النسخ المعتاد مباشرةً داخل نافذة الطرفية.

### 2. الإكمال التلقائي باستخدام Tab

هذه ميزة ممتازة جدًا، وتوفر عليك وقتًا كبيرًا.

```bash
cd Doc<Tab>
```

إذا كانت هناك أسماء متعددة مطابقة، سيعرض لك النظام الخيارات المتاحة. إن كان هناك خيار واحد فقط، فسيكمله تلقائيًا لك.

هذه الميزة مفيدة جدًا عندما تكون مسارات المجلدات طويلة، مثل:

```bash
cd ~/Documents/Project/lesson-1
```

بدلاً من كتابة كل شيء حرفًا بحرف، يمكنك كتابة جزء منه ثم الضغط على Tab.

### 3. استخدام النقطة `.`

النقطة `.` تشير إلى <Mark>المجلد الحالي</Mark>.

لذا إذا كنت داخل مشروع ما وتريد فتحه في VS Code، يمكنك كتابة:

```bash
code .
```

هذا الأمر يفتح المجلد الحالي مباشرة في محرر الـ VS Code.

<LessonNote>
  ستستخدم هذه الخاصية كثيرًا في المستقبل، خصوصًا مع Git، لأنك ستكتب أحيانًا
  أوامر مثل `git add .`.
</LessonNote>

## فتح الملفات من الطرفية

إذا قمت بتثبيت VS Code، فيمكنك فتح أي ملف أو مجلد مباشرة من الطرفية.

### على Linux

```bash
code my-project
```

أو

```bash
code my-file.html
```

### على macOS

بعد تثبيت VS Code، أعد فتح الطرفية، ثم من داخل VS Code افتح <Mark>Command Palette</Mark> باستخدام:

```bash
Cmd + Shift + P
```

ثم ابحث عن:

```text
Shell Command: Install 'code' command in PATH
```

بعد ذلك، أعد تشغيل الطرفية، ثم جرّب:

```bash
code .
```

### على Windows

إذا تم تثبيت VS Code بشكل صحيح، غالبًا يمكنك استخدام الأمر التالي مباشرة:

```powershell
code .
```

وسيتم فتح المجلد الحالي داخل VS Code.

## ما الذي يجب أن تتذكره؟

في هذه المرحلة ستتعرف على أهم الأوامر الأساسية:

```bash
pwd      # يظهر المسار الحالي
ls       # يعرض محتويات المجلد الحالي
cd       # يغيّر المجلد الحالي
mkdir    # ينشئ مجلدًا جديدًا
touch    # ينشئ ملفًا جديدًا
rm       # يحذف ملفًا أو مجلدًا
mv       # ينقل أو يغيّر اسم ملف/مجلد
cp       # ينشئ نسخة من ملف
code .   # يفتح المجلد الحالي في VS Code
```

هذه الأوامر تشكل الأساس الذي ستبني عليه مهاراتك في البرمجة والعمل مع المشاريع لاحقًا.

## الخلاصة

سطر الأوامر ليس شيئًا مخيفًا أو معقدًا كما يظنه البعض. إنه مجرد وسيلة أخرى للتفاعل مع الكمبيوتر، وهي ليست أسوأ من النقر على الأيقونات؛ بل إنها غالبًا أسرع وأكثر فاعلية للمطورين.

إذا حافظت على استخدامه بشكل منتظم، ستلاحظ أن الأوامر الأساسية تصبح جزءًا طبيعيًا من روتينك اليومي، خاصةً عندما تبدأ في التعامل مع المشاريع والملفات الكبيرة.

بمجرد أن تتقن `cd`, `ls`, `mkdir`, `touch`, و`rm`، ستكون قد خطوت أولى الخطوات المهمة في رحلتك كـ <Mark>مطور ويب</Mark>.
